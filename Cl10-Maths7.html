7.2 · The distance formula

02How far apart are two points?

Draw a horizontal and a vertical line between the points and you have a right triangle. Its legs are the differences in x and y; Pythagoras gives the hypotenuse — the distance.

7.3 · The section formula

03Where does the point sit?

If a point P divides AB in the ratio m : n, it sits closer to the end with the smaller share. The formula is a weighted average of the two endpoints.

7.3 · The special case

04Midpoint, and what it unlocks

Put m = n = 1 and the section formula collapses into a simple average. That little fact solves a surprising number of problems — especially “find the fourth vertex” and “the centre of a circle”.

The midpoint

M = ((x₁ + x₂)/2, (y₁ + y₂)/2)

The midpoint of A(1, 2) and B(5, 6) is (3, 4) — average each coordinate separately.

Three uses worth knowing

1. The centre of a circle is the midpoint of any diameter.

2. In a parallelogram, the diagonals bisect each other — so both midpoints are equal.

3. A point on the x-axis has y = 0; on the y-axis, x = 0.

Reading the question carefully “Divides in the ratio 2 : 3” means AP : PB = 2 : 3. But “the ratio in which P divides AB” may need you to solve for m : n — set up the section formula, compare one coordinate, and solve.
Worked example

05Find the point on the x-axis

Find the point on the x-axis that is equidistant from (2, −5) and (−2, 9).

Step-through · equidistant point
On the x-axis, y is zero — that is the key.
Name the point. Any point on the x-axis is (x, 0).
Write both distances using the formula, with (x, 0) each time.
Set them equal. (x − 2)² + 25 = (x + 2)² + 81.
Expand. x² − 4x + 29 = x² + 4x + 85 → −8x = 56.
x = −7. The point is (−7, 0). The squares cancel — that is why you never need the square root here.
Square first, root later In “equidistant” problems, write the two squared distances equal. The square roots disappear and you are left with a linear equation.

07Four traps

01

Order inside the bracket

(x₂ − x₁) is squared, so the order does not matter — but forgetting the square does.

02

Ratio direction

2 : 3 from A to B is not 3 : 2. Swapping m and n moves the point to the other side.

03

Points on an axis

On the x-axis y = 0; on the y-axis x = 0. Using (x, y) and solving both wastes time.

04

Leave roots in surd form

√50 = 5√2. Simplify, but do not round unless asked.
