Statistics

Three numbers try to summarise a whole crowd: the mean says what a typical value would be if everything were shared equally, the median says who stands in the middle, the mode says what happens most often. This chapter teaches you to compute all three when the data arrives as a table of classes.

01What this chapter actually asks

In Class IX the data was a list of numbers. Now it comes as a table: marks 10–25, 25–40 and so on, with a count for each class. You no longer know the individual values — only how many fell in each band. Every formula here is a way of squeezing a number back out of that table.

Mean
balance point

Uses every value. Sensitive to extremes.

Median
middle value

Ignores how extreme the extremes are.

Mode
most frequent

The crowd favourite. Used for categories too.

The one assumption to remember Grouped data forgets where inside a class the values sat. So we assume every value in a class sits at its class mark (the midpoint). That assumption is why the grouped mean 62 differs slightly from the exact 59.3.

03Mean of grouped data — three methods, one answer

This is the heart of the chapter. Same table, three routes: direct, assumed mean and step deviation. They exist only to make the arithmetic easier; they must all land on the same number.

Direct

x̄ = Σfixi / Σfi

Multiply each class mark by its frequency, add, divide. Fine when the numbers are small.

Assumed mean

x̄ = a + Σfidi / Σfi

Pick any class mark as a, use d = x − a. The big numbers shrink to small deviations.

Step deviation

x̄ = a + h(Σfiui / Σfi)

Divide the deviations by the class size h as well. Best when all d are multiples of h.

How to choose in the exam Small class marks? Direct. Large numbers but equal class sizes? Step deviation — it is the fastest and the least error-prone. Unequal class sizes with large numbers? Step deviation still works: take h as a common divisor of the deviations, as Example 3 does with h = 20.
13.3 · The popular one

04Mode of grouped data

With grouped data you cannot see which value occurs most often — you can only see which class is busiest. That class is the modal class, and the mode is a point inside it, pulled towards the neighbouring class that is also crowded.

Mode = l + f1 − f02f1 − f0 − f2 × h

Reading the formula If the class after the modal class is just as busy (f2 close to f1), the mode slides towards the upper limit. If the class before is busier (f0 close to f1), it slides down. If both neighbours are equally busy, the mode sits exactly at the class mark.
13.4 · The middle

05Median, cumulative frequency and the ogive

The median needs the data in order, and grouped data is already in order — all you need is a running total. That running total is the cumulative frequency, and its graph is the ogive.

Before grouped data: the ungrouped median For a plain list, arrange the values in order. With 100 students' marks, the median is the average of the 50th and 51st observations. Build a cumulative frequency column (6, 26, 50, 78, 93, 97, 99, 100) and you see the 50th is 28 and the 51st is 29 — median 28.5. That is exactly the same cumulative-frequency thinking the grouped formula uses, just without the interpolation.

Less than, more than

A less than table adds frequencies downward and plots against upper class limits. A more than table subtracts downward and plots against lower limits. Both describe the same data.

If a question hands you a “less than” table, first convert it into ordinary classes by subtracting consecutive cumulative frequencies — Example 7 in the book does exactly that.

Reading a median correctly

The median class is the first class whose cumulative frequency reaches or passes n/2. Then

Median = l + n/2 − cff × h

l = lower limit of that class, cf = cumulative frequency of the class before it, f = its own frequency, h = class size.

07Three examples that carry the chapter

Example 1 · The 30 marks, three ways

Marks of 30 students in classes 10–25, …, 85–100. Mean comes out 62 by every method.

Step-through · Example 1
The table that appears in almost every board paper.
Class marks. 17.5, 32.5, 47.5, 62.5, 77.5, 92.5. Frequencies 2, 3, 7, 6, 6, 6.
Direct. Σfx = 1860, Σf = 30, so x̄ = 62.
Assumed mean. Take a = 47.5. Deviations are −30, −15, 0, 15, 30, 45, so Σfd = 435.
x̄ = 47.5 + 435/30 = 47.5 + 14.5 = 62. The choice of a does not matter — Activity 1 in the book asks you to prove that by trying every class mark.
Step deviation. h = 15, u = d/15 gives −2, −1, 0, 1, 2, 3 and Σfu = 29.
x̄ = 47.5 + 15(29/30) = 47.5 + 14.5 = 62. Same number, much smaller arithmetic.

Example 5 · Mode from a small table

Step-through · Example 5
Family sizes 1–3 to 9–11 with frequencies 7, 8, 2, 2, 1.
Find the busiest class. The largest frequency is 8, in 3–5. So the modal class is 3–5.
Read off the pieces. l = 3, h = 2, f₁ = 8, f₀ = 7, f₂ = 2.
Substitute. Mode = 3 + [(8 − 7)/(16 − 7 − 2)] × 2 = 3 + 2/7.
Answer. Mode = 3.286 family members. Just above the lower limit, because the class below (7) is almost as busy as the modal class.

Examples 7 & 8 · Median from a “less than” table, and finding x and y

Convert to classes: below 140 (4), 140–145 (11 − 4 = 7), 145–150 (29 − 11 = 18), 150–155 (11), 155–160 (6), 160–165 (5).

n/2 = 25.5, so the median class is 145–150 with cf = 11, f = 18, h = 5.

Median = 145 + (25.5 − 11)/18 × 5 = 145 + 4.03 = 149.03 cm.

Class marks 20, 30, 40, 50, 60, 70, 80; n = 35; Σfx = 1390.

Direct: 1390/35 = 39.71. Assumed mean (a = 50, Σfd = −360): 50 − 10.29 = 39.71. Step deviation (h = 10, Σfu = −36): 50 − 10.29 = 39.71.

Three routes, one answer — that is the check you should always perform mentally.

Take a = 200 and h = 20 (a common divisor of all the deviations), so u = (x − 200)/20.

Σfu = −106, n = 45 → x̄ = 200 + 20(−106/45) = 200 − 47.11 = 152.89.

The mean says: these bowlers took about 153 wickets each on average. Unequal class sizes do not stop the step-deviation method — they only stop the mode and median formulae.

Total: 76 + x + y = 100 → x + y = 24.

Median class is 500–600 with l = 500, f = 20, cf = 36 + x, h = 100.

525 = 500 + (50 − 36 − x)/20 × 100 → 25 = 5(14 − x) → x = 9, so y = 15.

Before the exam

09Five traps

01

Class mark, not class limit

The direct method uses midpoints. Using 10 instead of 17.5 for the class 10–25 quietly ruins the answer.

02

cf of the class before

In the median formula, cf is the cumulative frequency of the class preceding the median class — not of the median class itself.

03

Continuous classes

If classes are 118–126, 127–135 with gaps, convert to 117.5–126.5, 126.5–135.5 before using the formulae.

04

Unequal class sizes

The mode and median formulae assume equal h. With unequal sizes, find h as the common difference and handle each case as the question intends.

05

n vs n/2

The median class is where cumulative frequency first reaches n/2 — use n/2, not n.

12Frequently asked questions

Because assumed mean and step deviation are just the direct formula with the same number subtracted from every x. Subtracting a constant from every observation lowers the mean by exactly that constant, and adding it back restores the true value. No information is lost.

Any method earns full marks, provided the working table is shown. Step deviation is usually fastest for large numbers; direct is safest for small ones. Write the method's name in your answer.

The midpoint of a class: (upper limit + lower limit)/2. It represents every observation in that class, because grouped data no longer tells you where inside the class the values were.

Because of the midpoint assumption. In Example 1 the exact mean of the raw marks is 59.3, while the grouped mean is 62 — the classes “rounded” each value to its midpoint. More classes means a smaller difference.

Yes — it is then called multimodal. This chapter restricts itself to single-mode problems, but the idea of “the most frequent class” still applies.

An ogive is the graph of cumulative frequency. You plot cumulative frequency against class limits and join the points with a smooth curve. The median is the x-value at cumulative frequency n/2. Drawing it is optional in some papers but it is an excellent check on your calculated median.

It is an empirical (observed) relation, accurate for moderately skewed distributions, not an identity. Use it only when a question explicitly asks you to.

Chapter summary

15The formulae sheet

  • Mean, direct: x̄ = Σfixi / Σfi
  • Mean, assumed mean: x̄ = a + Σfidi/Σfi
  • Mean, step deviation: x̄ = a + h(Σfiui/Σfi)
  • Mode: l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h
  • Median: l + [(n/2 − cf)/f] × h
  • Cumulative frequency = running total of frequencies up to a class
  • Empirical relation: 3 Median = Mode + 2 Mean
