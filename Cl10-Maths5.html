01One step, two questions

Every AP is fixed by two numbers: where it starts (a) and how much it jumps each time (d). From those you can reach any term, or add up any number of terms.

Worked examples

05Two classic setups

Example · How many terms of 9, 17, 25, … give 636?

Step-through · sum problem
A quadratic hides inside every “how many terms” question.
Read a and d. a = 9, d = 8, Sₙ = 636.
Write the sum formula. n/2 [2(9) + (n − 1)8] = 636.
Simplify. n(18 + 8n − 8) = 1272 → n(8n + 10) = 1272.
Solve the quadratic. 8n² + 10n − 1272 = 0 → 4n² + 5n − 636 = 0.
n = 12 (the other root is negative and is rejected).

Example · The 200 logs

Step-through · stacking problem
20 in the bottom row, 19 above it, and so on.
Read a and d. a = 20, d = −1, Sₙ = 200.
Substitute. n/2 [40 − (n − 1)] = 200 → n(41 − n) = 400.
Solve. n² − 41n + 400 = 0 → (n − 16)(n − 25) = 0.
Choose sensibly. n = 25 would make the top row 20 − 24 = −4 logs, which is impossible. So 16 rows and the top row has 20 − 15 = 5 logs.

Before the exam

07Four traps

01

(n − 1), not n

The first term takes zero steps. Using n instead of n − 1 shifts every answer by one d.

02

n must be a positive whole number

If solving gives n = 12.5, that term simply is not in the AP — say so instead of rounding.

03

Two roots, one sensible

“How many terms” questions often give a quadratic with a negative root. Reject it with a reason.

04

Which formula for the sum?

If you know the last term, n/2(a + l) is quicker. If you know d, use n/2[2a + (n−1)d].

Chapter summary

13Five lines to revise

  • An AP has a fixed difference: d = aₖ − aₓ₋₁.
  • nth term: aₙ = a + (n − 1)d.
  • Sum: Sₙ = n/2[2a + (n − 1)d].
  • Sum with last term: Sₙ = n/2(a + l).
  • “How many terms” questions usually end in a quadratic — keep the positive whole root.
